                      Khoá API

                      Dán key vào ô rồi bấm Lưu. Key được lưu trong cơ sở dữ liệu của bạn, web chỉ hiện vài ký tự đầu/cuối. Để trống ô nào thì giữ nguyên key cũ.

                      Google: đăng nhập bằng Gmail & Google Lịch
                      1. Vào Google Cloud, tạo project, bấm Enable để bật Google Calendar API.
                      2. Vào Google Auth Platform: điền tên ứng dụng, email; chọn External. Ở mục Audience bấm Publish app (để không bị đăng xuất sau 7 ngày).
                      3. Mục Clients → Create client → loại Web application. Ở Authorized redirect URIs dán địa chỉ dưới đây, bấm Create.
                      4. Chép Client ID và Client secret dán vào 2 ô bên dưới rồi bấm Lưu.
